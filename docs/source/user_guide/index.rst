User Guide
==========

Welcome to the **Rolland** User Guide. This guide is structured to help you understand the core workflow of setting up and running a time-domain simulation.



.. grid:: 1 2 2 3
   :gutter: 3

   .. grid-item-card:: 1. Create a Track
      :link: create_track
      :link-type: doc

      Learn how to define components (Rails, Pads, Sleepers), assemble a track model, and set up the computational domain with PML boundaries.

   .. grid-item-card:: 2. Excite the Track
      :link: excite_track
      :link-type: doc

      Understand how to apply stationary impulses or moving loads, and how to run the time-domain solver.

   .. grid-item-card:: 3. Evaluate the Results
      :link: evaluate_results
      :link-type: doc

      Discover how to post-process simulation data, calculate Track Decay Rates (TDR), and compute mobilities.
