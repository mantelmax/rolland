Semi-Analytical Models
======================

.. note:: 
   The ``methods.semi_analytical`` package is provided solely for reference, benchmarking, and validation purposes against the core Rolland model.

The package provides Timoshenko beam discrete models and Kostovasilis continuous track solutions.
